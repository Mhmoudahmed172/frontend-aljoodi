# Graphik Arabic

The global font family is `"Graphik Arabic"` (see `src/app/globals.css`, `--font-sans`).
Drop the licensed files here so the `@font-face` rules resolve:

- `GraphikArabic-Regular.woff2` (400)
- `GraphikArabic-Medium.woff2` (500)
- `GraphikArabic-Semibold.woff2` (600)
- `GraphikArabic-Bold.woff2` (700)

Until then the browser uses a locally installed "Graphik Arabic" if available, else Cairo.
